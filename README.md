Selamat datang di repositori distribusi resmi aplikasi **T-LA Mobile**. 

T-LA (Tracking Lapangan) adalah ekosistem pemantauan kegiatan lapangan berbasis lokasi yang dirancang untuk menjaga kualitas, validitas, dan keterlacakan data di BPS Kabupaten Halmahera Utara. Ekosistem ini terdiri dari **Dashboard Web** (untuk manajemen dan monitoring admin) dan **Aplikasi Mobile** ini yang digunakan langsung oleh petugas di lapangan.

Repositori ini dikhususkan **hanya untuk mendistribusikan dan mengunduh versi rilis terbaru (file `.apk`)** dari aplikasi T-LA Mobile.

## ✨ Fitur T-LA Mobile

Aplikasi T-LA Mobile dirancang secara spesifik untuk mempermudah tugas pengumpulan data dengan fitur unggulan:

* 📍 **Precision Geofencing**: Memvalidasi lokasi petugas secara otomatis menggunakan poligon batas wilayah (SLS/Desa), bahkan saat *offline*.
* 📸 **Intelligent Watermarking**: Menyisipkan metadata anti-manipulasi (*tamper-proof*) seperti koordinat GPS, waktu, dan nama petugas pada setiap foto yang diambil dari kamera internal.
* 📝 **Dynamic E-Survey**: Memungkinkan petugas mengisi kuesioner elektronik dinamis secara langsung di dalam aplikasi sesuai dengan jenis kegiatannya.
* 📱 **Offline-First**: Berfungsi penuh tanpa koneksi internet. Semua isian dan foto akan disimpan dengan aman di perangkat lokal dan disinkronisasikan (*Smart Sync*) ke server secara efisien ketika ada jaringan internet.

## 🛠️ Cara Instalasi

1. **Unduh File APK:** Buka tautan di atas dan unduh file APK dari rilis yang tersedia.
2. **Izinkan Sumber Tidak Dikenal:** Jika muncul peringatan keamanan di perangkat Android Anda, buka *Pengaturan* > *Keamanan* > Aktifkan *Instal Aplikasi dari Sumber Tidak Dikenal* (atau izinkan browser/file manager Anda).
3. **Instal Aplikasi:** Buka file APK yang telah diunduh, lalu klik *Install*.
4. **Login:** Masuk ke dalam aplikasi menggunakan kredensial (Username & Password) yang telah diberikan oleh Admin Kabupaten.
